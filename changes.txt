=== FILE: cf-oscore/src/main/java/org/eclipse/californium/oscore/RequestEncryptor.java ===
Status: Modified

Summary:
Skips OSCORE encryption for phantom requests.

Changes:
- Added check: if request.getIsPhantomRequest(), return the request
  unmodified (skip encryptEncode)

Reasoning:
When the server's OSCORE layer processes an outgoing phantom request, it
would normally encrypt it. But phantom requests go through a
serialize-then-re-parse cycle, so the encryption happens on the receive side
instead. Skipping here prevents double encryption.

  option encoding). This is correct for phantom requests but the intent
  should be documented more clearly.
